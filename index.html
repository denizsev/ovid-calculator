      HOW DOES THIS WORK?

      Ovid is not an ordinary calculator: it tracks measurement error, units and exact values. All of it is optional — ignore it and it behaves like any other calculator.

      ±σ Error bars

      Carries the uncertainty of your measurement through the calculation.

      5.2±0.1 × 3 = 15.6 ± 0.3

      Units Unit-aware maths

      Put a unit after a number; the result finds its own unit and rejects mismatched ones.

      5 km + 300 m = 5.3 km · 100 km / 2 h = 50 km/h

      a/b Fraction mode

      Shows the exact value instead of a rounded decimal.

      1/3 + 1/6 = 1/2

      ⇢ Warp mode

      Instead of jumping to the answer, it walks through the order of operations.

      2 + 3 × 4 → 2 + 12 → 14

      ↔ "What if?"

      Tap a number on the display; it becomes a slider and the result follows it live.

      fx Scientific keys

      Trigonometry, logarithms, powers, factorial, mod. 2nd opens the inverse functions.

      Tools Number tools

      Prime factors, GCD/LCM, base conversion (2/8/10/16), list statistics.

      📈 Analytic geometry

      The graph icon above opens a separate page for functions, points and circles. Same engine.

      y = sin(x) · x² + y² = 9 · (2, 3)

      A Size

      Scales the keys and text through three steps.

      Keyboard shortcuts
